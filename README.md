# 🛡️ CyberGuard — Cyber Attack & Defense Simulator

### Simulate Attacks. Detect Threats. Defend Systems.

CyberGuard is a Java-based Cyber Attack & Defense Simulator that demonstrates how cybersecurity threats can be simulated, monitored, and managed through an interactive desktop application.

Built using **Java and Java Swing**, CyberGuard provides a centralized security dashboard where users can explore simulated cyber attacks, monitor network activity, manage potential threats, and perform defensive actions such as network isolation and recovery.

The project aims to demonstrate fundamental cybersecurity concepts through practical implementation, modular architecture, and an interactive graphical interface.

---

## 🚀 Features

### 1. Cyber Attack Simulation
- Simulate different cyber attack scenarios.
- Observe how simulated attacks interact with the application's security components.
- Understand the relationship between attack activities and defensive mechanisms.

### 2. Network Monitoring
- Monitor network-related activity through the dashboard.
- View relevant security information.
- Observe changes during simulated attack scenarios.

### 3. Threat Detection & Management
- Manage threats identified or generated within the simulator.
- Track security-related events.
- Organize threat information through dedicated management components.

### 4. Network Isolation & Recovery
- Isolate a network component using the available defensive controls.
- Recover an isolated component.
- Demonstrate the concept of containing and recovering from security incidents.

### 5. Security Event Logging
- Record security-related activities.
- Maintain logs of application events.
- Review actions performed during simulation and defense operations.

### 6. Interactive Security Dashboard
- Built with Java Swing.
- Centralized access to security and network management features.
- Modern dark-themed interface.
- Organized views for attack simulation, threat monitoring, and defense operations.

## 💻 Getting Started

Follow these steps to run CyberGuard on your local machine.

### Prerequisites

Make sure you have:

- Java Development Kit (JDK) installed.
- Visual Studio Code or another Java-compatible IDE.
- Java Extension Pack for VS Code (recommended).

Check your Java installation:

```bash
java -version
javac -version
```

### 1. Clone the Repository

```bash
git clone https://github.com/avniporwal8929-create/Cyber-Attack-Defence-Simulator.git
```

### 2. Open the Project

```bash
cd Cyber-Attack-Defence-Simulator
code .
```

### 3. Run the Application

Open the project in VS Code.

Locate the Java file containing the application's `main()` method and run it using the **Run Java** option.

If your project uses packages or external dependencies, make sure the Java project configuration is set up correctly before running.

## 🔄 How CyberGuard Works

CyberGuard demonstrates a basic cybersecurity response workflow:

**Step 1 — Attack Simulation**

Launch an available simulated attack scenario.

**Step 2 — Monitoring**

Observe network activity and security-related information.

**Step 3 — Threat Management**

Review the threats represented within the application.

**Step 4 — Defensive Response**

Use available defensive controls, including network isolation.

**Step 5 — Recovery**

Recover the isolated component and review the recorded security events.
